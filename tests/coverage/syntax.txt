# What haruspex does with each construct ScriptDom parses: every node type of the kinds a procedure's body is made of
# (ScriptDomNodes lists them, and tests/coverage/README.md says how they were chosen) in ScriptDom 180.140.0, and every
# operator, join, set operator and assignment of its enums.
# CoveragePageTests fails when ScriptDom has a type or operator with no entry here, or an entry names one it lacks, and runs
# every example through haruspex to check its claim. tests/coverage/README.md explains the format; in short, each line is
#
#   Node | Syntax | Claim | Section | What | Example
#
# Node     a ScriptDom type (IfStatement) or an enum member (BinaryExpressionType.Add).
# Syntax   the construct as T-SQL writes it.
# Claim    modelled: haruspex reads it and types what it gives (the example gives no unknown).
#          no-effect: haruspex reads it, and it changes no result (the example gives no unknown).
#          unknown <reason>: haruspex gives an unknown with this reason (the example gives it).
#          partly <reason>: some forms are modelled (the first example gives no unknown) and others give an unknown with
#            this reason (the second example, after &&, gives it).
#          not-in-a-body: the parser refuses it in a procedure's body (the example, as a body, doesn't parse).
#          not-parsed: the parser never makes this node from a procedure's body (the example, if any, has none).
#          within <Node>: a part of another construct, which its entry describes.
#          A statement with no example claims what a statement the walker has no case for gives: unknown
#          unsupported-statement; the test checks the walker has no case for it.
# Section  a heading of src/Haruspex.SqlServer.Inference/README.md that explains it, or empty.
# What     one sentence: how its result is typed and when it is null, or what haruspex says instead.
# Example  a procedure body over the tables in CoverageProbe; \| writes a bar inside it.
#
# A [heading] starts a section of the page.

[Statements that return or write rows]
SelectStatement | SELECT | modelled | Result sets are positional | Each SELECT without INTO returns a result set, typed column by column; SELECT … INTO a temporary table creates it. | SELECT id, name FROM dbo.toy;
InsertStatement | INSERT | modelled | DML | Writes rows, typed for a temporary table or variable it writes and for its OUTPUT; INSERT … EXEC runs the procedure into the table. | INSERT INTO dbo.box (id, toy_id, qty) VALUES (1, 1, 2);
UpdateStatement | UPDATE | modelled | DML | Changes rows; a column it sets in a temporary table or variable takes the new value's type too. | UPDATE dbo.box SET qty = qty + 1 WHERE id = 1;
DeleteStatement | DELETE | modelled | DML | Removes rows, which changes no column's type. | DELETE FROM dbo.box WHERE id = 1;
MergeStatement | MERGE | modelled | DML | Each WHEN clause is the insert, update or delete it holds, into a temporary table or table variable too. | MERGE dbo.box AS b USING dbo.toy AS t ON b.toy_id = t.id WHEN MATCHED THEN UPDATE SET qty = 0 WHEN NOT MATCHED THEN INSERT (id, toy_id, qty) VALUES (t.id, t.id, 1);
AssignmentSetClause | SET c = x in UPDATE | modelled | DML | The column, in a temporary table or variable, takes the value's type too. | UPDATE dbo.box SET qty = 1;
FunctionCallSetClause | SET c.WRITE( … ) in UPDATE | modelled | DML | The column keeps its type and its nulls, but only its type's facets and no JSON it held; on a permanent table it changes no column's type. | UPDATE dbo.toy SET note.WRITE(N'x', 0, 1) WHERE id = 1; CREATE TABLE #t (c nvarchar(max) NULL); UPDATE #t SET c.WRITE(N'x', 0, 1); SELECT c FROM #t;
TruncateTableStatement | TRUNCATE TABLE | no-effect | DML | Removes every row and fires no trigger. | TRUNCATE TABLE dbo.box;
ExecuteStatement | EXECUTE | partly dynamic-sql | Calls | A call of a procedure in the project returns what it returns, unless WITH RESULT SETS changes it (below), and one of SQL Server's own the catalogue lists what it lists; a string of dynamic SQL can't be read, so the results after it can't be listed. | EXEC dbo.helper; && EXEC sp_executesql N'SELECT 1 AS a';
BulkInsertStatement | BULK INSERT | unknown unsupported-statement | | Not modelled. | BULK INSERT dbo.box FROM 'boxes.csv';
InsertBulkStatement | INSERT BULK | unknown unsupported-statement | | Not modelled. | INSERT BULK dbo.box (id int);
ReadTextStatement | READTEXT | unknown unsupported-statement | | Not modelled. | DECLARE @p varbinary(16); READTEXT dbo.toy.note @p 0 1;
WriteTextStatement | WRITETEXT | unknown unsupported-statement | | Not modelled. | DECLARE @p varbinary(16); WRITETEXT dbo.toy.note @p 'x';
UpdateTextStatement | UPDATETEXT | unknown unsupported-statement | | Not modelled. | DECLARE @p varbinary(16); UPDATETEXT dbo.toy.note @p 0 NULL 'x';
CopyStatement | COPY INTO | unknown unsupported-statement | | Not modelled. | COPY INTO dbo.box FROM 'https://example.com/boxes.csv';
ReceiveStatement | RECEIVE | unknown unsupported-statement | | Not modelled. | RECEIVE TOP (1) * FROM dbo.inbox;

[Calls]
ExecutableProcedureReference | EXEC procedure | modelled | Calls | The procedure called, whose result sets arrive where it is called. | EXEC dbo.helper;
ExecutableStringList | EXEC ( 'string' ) | unknown dynamic-sql | Calls | Dynamic SQL, which can't be read, so the results after it can't be listed. | EXEC ('SELECT 1 AS a');
ExecuteOption | EXEC … WITH RECOMPILE | no-effect | Calls | Changes no result. | EXEC dbo.helper WITH RECOMPILE;
ResultSetsExecuteOption | EXEC … WITH RESULT SETS | partly unsupported-statement | Calls | UNDEFINED is as no clause; declared result sets or NONE aren't modelled, so the results after the call are unknown. | EXEC dbo.helper WITH RESULT SETS UNDEFINED; && EXEC dbo.helper WITH RESULT SETS NONE;
InlineResultSetDefinition | RESULT SETS (( columns )) | unknown unsupported-statement | Calls | Not modelled yet: the declared columns rename the callee's and convert its values. | EXEC dbo.helper WITH RESULT SETS ((renamed varchar(3) NULL));
SchemaObjectResultSetDefinition | RESULT SETS ( AS OBJECT … ) | unknown unsupported-statement | Calls | Not modelled yet. | EXEC dbo.helper WITH RESULT SETS (AS OBJECT dbo.box);
ResultSetDefinition | RESULT SETS ( AS FOR XML ) | unknown unsupported-statement | Calls | Not modelled yet. | EXEC dbo.helper WITH RESULT SETS (AS FOR XML);

[Statements that steer the flow]
BeginEndBlockStatement | BEGIN … END | modelled | The state | Its statements in order. | BEGIN SELECT 1 AS a; END
BeginEndAtomicBlockStatement | BEGIN ATOMIC … END | modelled | The state | As BEGIN … END: its statements in order. | BEGIN ATOMIC WITH (TRANSACTION ISOLATION LEVEL = SNAPSHOT, LANGUAGE = N'English') SELECT 1 AS a; END
IfStatement | IF … ELSE | modelled | Joins, where paths meet | Each branch is walked from the state before it, and where they meet their states are joined. | IF (SELECT COUNT(*) FROM dbo.toy) > 1 SELECT 1 AS a; ELSE SELECT 2 AS a;
WhileStatement | WHILE | modelled | Joins, where paths meet | Its body is walked until another pass changes nothing; a loop that may return result sets makes them vary. | DECLARE @n int = 0; WHILE @n < 3 SET @n += 1; SELECT @n AS n;
BreakStatement | BREAK | modelled | Joins, where paths meet | Leaves the loop, joining its state with the loop's end. | WHILE 1 = 1 BREAK; SELECT 1 AS a;
ContinueStatement | CONTINUE | modelled | Joins, where paths meet | Goes back to the loop's head, joining its state there. | DECLARE @n int = 0; WHILE @n < 3 BEGIN SET @n += 1; CONTINUE; END SELECT @n AS n;
ReturnStatement | RETURN | modelled | The state | Ends the procedure; its result sets are those before it. | SELECT 1 AS a; RETURN;
TryCatchStatement | BEGIN TRY … BEGIN CATCH | modelled | The state | CATCH is reached from the state before any statement of TRY that may fail. | BEGIN TRY SELECT 1 AS a; END TRY BEGIN CATCH SELECT 2 AS b; END CATCH
ThrowStatement | THROW | modelled | The state | Ends the call, or reaches CATCH. | SELECT 1 AS a; THROW 50000, 'stop', 1;
RaiseErrorStatement | RAISERROR | modelled | The state | Of severity 11 or more it ends the call, or reaches CATCH; below that it is a message. | RAISERROR ('note', 10, 1); SELECT 1 AS a;
RaiseErrorLegacyStatement | RAISERROR number 'text' | not-in-a-body | | The form SQL Server 2000 had, which the parser for compatibility level 170 refuses. | RAISERROR 50000 'old';
GoToStatement | GOTO | unknown unsupported-statement | | Not modelled: a jump the walker doesn't follow, so the result sets after it can't be listed. | GOTO done; done: SELECT 1 AS a;
LabelStatement | label: | unknown unsupported-statement | | Not modelled, as GOTO isn't. | done: SELECT 1 AS a;
WaitForStatement | WAITFOR | unknown unsupported-statement | | Not modelled. | WAITFOR DELAY '00:00:01'; SELECT 1 AS a;

[Statements that hold state]
DeclareVariableStatement | DECLARE @v | modelled | The state | Declares the variable with its type, holding its initial value or NULL. | DECLARE @n int = 1; SELECT @n AS n;
SetVariableStatement | SET @v = … | partly unsupported-statement | The state | Assigns the value, converted to the variable's type; a variable of a CLR type set by a method call isn't read. | DECLARE @n int; SET @n = 2; SELECT @n AS n; && DECLARE @g geography; SET @g.STSrid = 4326;
DeclareTableVariableStatement | DECLARE @t TABLE | modelled | The state | Declares the table variable with its columns. | DECLARE @t TABLE (a int NOT NULL); SELECT a FROM @t;
DeclareCursorStatement | DECLARE … CURSOR | modelled | Cursors | Declares the cursor, whose FETCH reads its query's columns. | DECLARE c CURSOR FOR SELECT id FROM dbo.toy; OPEN c; CLOSE c; DEALLOCATE c;
CursorDefinition | the cursor's options and query | within DeclareCursorStatement | | |
FetchType | NEXT, PRIOR, FIRST, … in FETCH | within FetchCursorStatement | | |
OpenCursorStatement | OPEN | no-effect | Cursors | Returns nothing. | DECLARE c CURSOR FOR SELECT id FROM dbo.toy; OPEN c;
FetchCursorStatement | FETCH | modelled | Cursors | FETCH … INTO sets its variables to the cursor's columns; FETCH without INTO returns one row of them. | DECLARE @i int; DECLARE c CURSOR FOR SELECT id FROM dbo.toy; OPEN c; FETCH NEXT FROM c INTO @i; SELECT @i AS i;
CloseCursorStatement | CLOSE | no-effect | Cursors | Returns nothing. | DECLARE c CURSOR FOR SELECT id FROM dbo.toy; OPEN c; CLOSE c;
DeallocateCursorStatement | DEALLOCATE | no-effect | Cursors | Returns nothing. | DECLARE c CURSOR FOR SELECT id FROM dbo.toy; DEALLOCATE c;
CreateTableStatement | CREATE TABLE | partly unsupported-statement | A temporary table's columns | A temporary table is created with its columns, or with its query's as SELECT … INTO makes them (`WITH (DISTRIBUTION = …) AS SELECT`); a permanent one isn't modelled. | CREATE TABLE #t (a int NOT NULL); SELECT a FROM #t; && CREATE TABLE dbo.made (a int);
DropTableStatement | DROP TABLE | partly unsupported-statement | A temporary table's columns | Dropping temporary tables removes them; dropping a permanent one isn't modelled. | CREATE TABLE #t (a int); DROP TABLE #t; && DROP TABLE dbo.box;
AlterTableAddTableElementStatement | ALTER TABLE … ADD | partly unsupported-statement | A temporary table's columns | A column added to a temporary table joins its columns; altering a permanent table isn't modelled. | CREATE TABLE #t (a int); ALTER TABLE #t ADD b int NULL; SELECT a, b FROM #t; && ALTER TABLE dbo.box ADD note int NULL;
AlterTableAlterColumnStatement | ALTER TABLE … ALTER COLUMN | partly unsupported-statement | A temporary table's columns | A temporary table's column takes its new type; a permanent one isn't modelled. | CREATE TABLE #t (a int); ALTER TABLE #t ALTER COLUMN a bigint NOT NULL; SELECT a FROM #t; && ALTER TABLE dbo.box ALTER COLUMN qty bigint;
AlterTableDropTableElementStatement | ALTER TABLE … DROP | partly unsupported-statement | A temporary table's columns | A column dropped from a temporary table leaves it; a permanent table isn't modelled. | CREATE TABLE #t (a int, b int); ALTER TABLE #t DROP COLUMN b; SELECT a FROM #t; && ALTER TABLE dbo.box DROP COLUMN qty;
CreateIndexStatement | CREATE INDEX | partly unsupported-statement | A temporary table's keys | A unique index without a filter on a temporary table is a key from there on, and any other changes nothing; one on a permanent table isn't modelled. | CREATE TABLE #t (a int); CREATE UNIQUE INDEX ux ON #t (a); && CREATE INDEX ix ON dbo.box (qty);
AlterIndexStatement | ALTER INDEX | partly unsupported-statement | A temporary table's keys | On a temporary table, DISABLE stops a key being enforced and REBUILD enables it again; on a permanent table it isn't modelled. | CREATE TABLE #t (a int, INDEX ux UNIQUE (a)); ALTER INDEX ux ON #t DISABLE; && ALTER INDEX ALL ON dbo.box REBUILD;
DropIndexStatement | DROP INDEX | partly unsupported-statement | A temporary table's keys | On a temporary table, the key of the index dropped holds no longer; on a permanent table it isn't modelled. | CREATE TABLE #t (a int, INDEX ux UNIQUE (a)); DROP INDEX ux ON #t; && DROP INDEX ix ON dbo.box;

[Queries]
QuerySpecification | SELECT … FROM … | modelled | Result sets are positional | Its columns, typed one by one, over the rows its sources and filters give. | SELECT id FROM dbo.toy WHERE id > 1;
BinaryQueryExpression | UNION, EXCEPT, INTERSECT | modelled | Set operations | Columns are combined by position, each of the type of highest precedence. | SELECT id FROM dbo.toy UNION SELECT toy_id FROM dbo.box;
QueryParenthesisExpression | ( query ) | modelled | Set operations | The query inside. | (SELECT id FROM dbo.toy) UNION ALL (SELECT id FROM dbo.box);
BinaryQueryExpressionType.Union | UNION [ALL] | modelled | Set operations | Each column's type is that of highest precedence; NULL where either side is. | SELECT id FROM dbo.toy UNION SELECT toy_id FROM dbo.box;
BinaryQueryExpressionType.Except | EXCEPT | modelled | Set operations | The left side's rows, so its columns. | SELECT id FROM dbo.toy EXCEPT SELECT toy_id FROM dbo.box;
BinaryQueryExpressionType.Intersect | INTERSECT | modelled | Set operations | Rows both sides hold. | SELECT id FROM dbo.toy INTERSECT SELECT toy_id FROM dbo.box;
SelectScalarExpression | column or expression in SELECT | modelled | Result sets are positional | A column of the result, named by its alias or the column it reads. | SELECT price AS p FROM dbo.toy;
SelectStarExpression | * and t.* | modelled | `SELECT *` | Expanded into the columns of the tables the project defines. | SELECT * FROM dbo.box;
SelectSetVariable | SELECT @v = … | modelled | The state | Sets the variable, from the last row read or left as it was over no rows; returns nothing. | DECLARE @n int; SELECT @n = id FROM dbo.toy; SELECT @n AS n;
WithCtesAndXmlNamespaces | WITH | modelled | CTEs | The common table expressions a query reads. | WITH c AS (SELECT id FROM dbo.toy) SELECT id FROM c;
CommonTableExpression | name AS ( query ) | modelled | CTEs | A named query, read as a table; a recursive one has its anchor's types, and its nullability is found by reading its recursive members until nothing changes. | WITH c (n) AS (SELECT 1 UNION ALL SELECT n + 1 FROM c WHERE n < 3) SELECT n FROM c;
XmlNamespaces | WITH XMLNAMESPACES | unknown unsupported-query | | Not modelled. | WITH XMLNAMESPACES ('urn:toy' AS t) SELECT id FROM dbo.toy;
FromClause | FROM | modelled | Result sets are positional | Its sources, joined. | SELECT t.id FROM dbo.toy AS t;
WhereClause | WHERE | modelled | Refinement | Filters rows, and what it proves about a column (such as IS NOT NULL) holds after it. | SELECT price FROM dbo.toy WHERE price IS NOT NULL;
GroupByClause | GROUP BY | partly unsupported-query | Aggregates and scalar subqueries | One row per group; GROUP BY ALL, whose groups include rows WHERE rejects with NULL aggregates, isn't modelled. | SELECT toy_id, SUM(qty) AS n FROM dbo.box GROUP BY toy_id; && SELECT toy_id, SUM(qty) AS n FROM dbo.box WHERE qty > 0 GROUP BY ALL toy_id;
HavingClause | HAVING | modelled | Refinement | Filters groups. | SELECT toy_id FROM dbo.box GROUP BY toy_id HAVING SUM(qty) > 1;
