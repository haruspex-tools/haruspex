# HAR3007: a procedure's key uses a wildcard

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A key of `procedures` uses `*` or `?`, but it names one procedure.

## Why haruspex reports it

Overrides are for one procedure: a wildcard would apply them to procedures with different results.

## What to do

Name the procedure. To use `*` or `?` in a name, write that part in brackets, as `[a*b]`.

## Example

```text
haruspex.json:1:93: error HAR3007: procedures["lib.get_*"]: names one procedure, so it cannot use * or ?; write a part that holds them in brackets, as [a*b].
```
