# HAR6022: no database is found to read

**Error.** Found by `haruspex init`. Nothing is written, and the exit code is 2.

## What it means

`haruspex init` found no project file (`.sqlproj`), DACPAC or `.sql` file in the working directory or the four folders
below it. It passes over hidden folders, `node_modules`, and `bin` and `obj` but for a DACPAC a build wrote there.

## Why haruspex reports it

A config file needs a source to read. `init` writes one only when it found the database's files, so the first
`haruspex generate` reads something.

## What to do

Run `haruspex init` beside the database's files, or name them: `haruspex init path/to/Sales.sqlproj`, a `.dacpac`, or the
folder of `.sql` files.

## Example

```text
haruspex: error HAR6022: found no .sqlproj, .dacpac or .sql file in the working directory or the four folders below it. Run it beside the database's files, or name them: haruspex init path/to/Sales.sqlproj.
```
