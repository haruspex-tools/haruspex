# HAR4303: generated names clash

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

Two objects would get the same generated name.

## Why haruspex reports it

Two declarations of one name can't both be in the generated module, and numbering one would make a name depend on what
else exists.

## What to do

Give one its own name with an override, give a schema a `prefix`, or add a naming `replace` rule that tells them apart,
as the message suggests.

## Example

```text
haruspex.json:1:46: error HAR4303: schemas.lib: "GetBook" would name both the procedure lib.get_book and the procedure lib.get_book#. Generated names must not clash: add a naming "replace" rule that tells their names apart (such as { "pattern": "#$", "with": "Row" }), or give one of them its own name with a "name" override in "procedures".
```
