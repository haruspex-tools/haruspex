# HAR3151: a keyword haruspex doesn't check

**Warning.** Found reading the config file. The run goes ahead.

## What it means

A JSON Schema keyword haruspex doesn't support yet.

## Why haruspex reports it

The generated schema doesn't check it, so the declared type is never narrower than the schema says, but it may be wider.

## What to do

Remove the keyword, or check it in your application.

## Example

```text
haruspex.json:1:145: warning HAR3151: procedures["lib.p"].results.json.pattern: is not supported yet, so the generated schema does not check it.
```
