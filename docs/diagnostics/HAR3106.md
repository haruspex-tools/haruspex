# HAR3106: a schema of several types

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A schema with more than one type besides `null`.

## Why haruspex reports it

A value of several types isn't supported in a declaration yet.

## What to do

Declare one type, or the one your application needs.

## Example

```text
haruspex.json:1:135: error HAR3106: procedures["lib.p"].results.json.type: can have only one type besides "null": a value of several types is not supported yet.
```
