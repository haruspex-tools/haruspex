# HAR3106: a schema of several types

**Error.** **Retired.** It was found reading the config file; haruspex no longer reports it, and its number is never given out
again.

## What it meant

A schema with more than one type besides `null`.

## Why it is retired

A value of several types wasn't supported in a declaration. A schema of several types is read as a value of any of them, a union, each with the keywords written for it. Reading it so is wider than refusing it, never narrower, so a value the schema allows is still accepted.

## What to do

Nothing: the declaration is read as it is.

**See also:** [Decision 0036](../decisions/0036-diagnostics-have-stable-codes.md), [the configuration reference](../configuration.md).
