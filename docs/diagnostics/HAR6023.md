# HAR6023: more than one database to read

**Error.** Found by `haruspex init`. Nothing is written, and the exit code is 2.

## What it means

`haruspex init` found more than one project file, or no project file and more than one DACPAC, and can't tell which is
the application's. The message names each.

## Why haruspex reports it

A repository may hold several databases, or a build's Debug and Release copies of one package. Picking one would be a guess,
and a wrong guess would type another database's procedures.

## What to do

Name the one to read: `haruspex init Sales/Sales.sqlproj`. For several databases, run `init` in a folder for each, so that
each is a module of its own (`haruspex generate --all` runs them all).

## Example

```text
haruspex: error HAR6023: found 2 project files, Audit/Audit.sqlproj and Sales/Sales.sqlproj, and can't tell which is the application's. Name one: haruspex init Audit/Audit.sqlproj.
```
