# HAR4106: an override of a shared recursive type

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

An override inside the recursive type a function builds by calling itself.

## Why haruspex reports it

Every procedure that reaches the type shares it, so an override for one would change it for all.

## What to do

Override the value where the procedure's own results hold it, above the shared type.

## Example

```text
haruspex.json:1:122: error HAR4106: procedures["lib.get_book"].paths["[].children[]"]: the value at results[0][].children[] is the recursive type of lib.tree, which every procedure that reaches it shares, so it can't be overridden for one of them.
```
