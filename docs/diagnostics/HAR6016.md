# HAR6016: a selected procedure's result sets are unknown

**Error.** Found by `haruspex check`, comparing with what is committed. The check fails, with exit code 1, and nothing is
written.

## What it means

A procedure the config file selects has result sets haruspex can't list (dynamic SQL, a procedure chosen when it runs, code
outside the project), and the config file doesn't declare them. `generate` warns of it with
[HAR4204](HAR4204.md); `check` fails.

## Why haruspex reports it

Selecting a procedure claims that it is an interface. Its results unknown, the module can't check what it returns, and the
check can't tell when that changes.

## What to do

Declare the results in the config file under `procedures["…"].results`, as `"none"` or a JSON Schema, with `why`; or
leave the procedure out of the selection.

## Example

```text
db/p1.sql:1:1: error HAR6016: lib.p: its result sets are unknown, and check passes a selected procedure only when they are known or declared. Declare them in haruspex.json under procedures["lib.p"].results, as "none" or a JSON Schema, or leave the procedure out of the selection.
```
