# HAR6019: options that can't go together

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

Either `--all` and `--config` are both given, or a source, `--include`, `--out` or `--baseline` is given with several modules
(`--all`, or more than one `--config`).

## Why haruspex reports it

`--all` finds the config files itself, so a list beside it would be ignored or doubled. A source, a selection, an output
folder and a baseline are each one module's: given once for several, every module would read the same project, select the
same procedures, write to the same folder and be judged against the same baseline.

## What to do

Give `--all` or `--config`, not both. With several modules, put the source, the selection, `out` and `baseline` in each
module's config file.

## Example

```text
haruspex: error HAR6019: a source, --include, --out and --baseline are for one module; with several config files, each says its own source, selection, out and baseline.
```
