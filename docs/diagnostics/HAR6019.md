# HAR6019: options that can't go together

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

Either `--all` and `--config` are both given, or a source, `--include` or `--out` is given with several modules (`--all`, or
more than one `--config`).

## Why haruspex reports it

`--all` finds the config files itself, so a list beside it would be ignored or doubled. A source, a selection and an output
folder are each one module's: given once for several, every module would read the same project, select the same procedures
and write to the same folder.

## What to do

Give `--all` or `--config`, not both. With several modules, put the source, the selection and `out` in each module's config
file.

## Example

```text
haruspex: error HAR6019: a source, --include and --out are for one module; with several config files, each says its own source, selection and out.
```
