# HAR4108: exact values declared without a value set

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

`"values": "exact"` on a value with no value set.

## Why haruspex reports it

A value set is inferred from a `CHECK` constraint on a column the value passes through unchanged; without one there is
nothing to make exact.

## What to do

Override the value's type instead, or add the constraint.

## Example

```text
haruspex.json:1:122: error HAR4108: procedures["lib.get_book"].paths["[].title"]: the value at results[0][].title has no value set to declare exact. A value set is inferred from a CHECK constraint on a column the value passes through unchanged; canonical value sets for other cases are planned, not done.
```
