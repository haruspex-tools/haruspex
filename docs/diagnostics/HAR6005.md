# HAR6005: no output folder is given

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

Neither `--out` nor the config file says where to write.

## Why haruspex reports it

A run never guesses where to write.

## What to do

Give `--out`, or `out` in the config file.

## Example

```text
haruspex: error HAR6005: give --out, the folder to write to, or a config file with "out".
```
