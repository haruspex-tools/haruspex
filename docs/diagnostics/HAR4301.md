# HAR4301: a procedure that can't be named

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

A procedure the naming rules can't name: the name they make is empty, isn't an identifier, or is a reserved word.

## Why haruspex reports it

Generated names are identifiers in the generated code.

## What to do

Give the procedure a `name`, or change the naming rules the message points at.

## Example

```text
haruspex.json:1:87: error HAR4301: naming: the procedure lib.book# cannot be named: "case": "preserve" gives 'book#', which is not a valid identifier (an ASCII letter, _ or $, then letters, digits, _ or $). Add a replacement, or give it a name in "procedures".
```
