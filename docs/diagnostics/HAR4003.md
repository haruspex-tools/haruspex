# HAR4003: an exclude matches nothing

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

An `exclude` pattern removes nothing the includes selected.

## Why haruspex reports it

A stale exclude would quietly stop excluding the day a procedure of that name comes back.

## What to do

Remove it, or correct it.

## Example

```text
haruspex.json:1:85: error HAR4003: schemas.lib.exclude[0]: '*_old' excludes nothing: it matches no procedure that "include" selects in the schema "lib". Remove it.
```
