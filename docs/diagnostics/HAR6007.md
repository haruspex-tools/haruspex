# HAR6007: nothing is selected

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

Nothing is selected: no `--include`, and no schema of the config file has an `include`.

## Why haruspex reports it

Typing every procedure is something asked for, never the default.

## What to do

Give `--include` (`'*.*'` for every procedure), or a schema with `include` in the config file.

## Example

```text
haruspex: error HAR6007: nothing is selected: give --include, or a config file whose "schemas" include procedures. Use '*.*' to type every procedure.
```
