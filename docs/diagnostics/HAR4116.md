# HAR4116: a JSON Schema named in the SQL where haruspex doesn't read one

**Warning.** Found applying the config file to the project. The run goes on: it declares nothing.

## What it means

The extended property `haruspex.jsonSchema` is on an object, a schema or anything else that is neither a column nor a parameter.
It is read only on a table's column and on a procedure's or function's parameter, as `columns` and `parameters` in the config
file declare them.

## Why haruspex reports it

The property looks like a declaration, and it changes nothing. Saying so keeps the team from relying on it.

## What to do

Name the schema on the table column the JSON is stored in, or on the parameter that takes it, or remove the property.

## Example

```text
db/p2.sql:1:1: warning HAR4116: The JSON Schema named on lib.save_book isn't read: haruspex reads one on a table's column or a procedure's or function's parameter only.
```
