# HAR4116: a JSON Schema named in the SQL where haruspex doesn't read one

**Warning.** Found applying the config file to the project. The run goes on: it declares nothing.

## What it means

The extended property `haruspex.jsonSchema` is on a procedure's or function's parameter, or on an object rather than a column.
It is read only on a table's column, as `columns` in the config file declares only a table's column.

## Why haruspex reports it

The property looks like a declaration, and it changes nothing: JSON read from the parameter is typed as it would be without it.
Saying so keeps the team from relying on it.

## What to do

Name the schema on the table column the JSON is stored in, if there is one, or remove the property. Declaring a parameter's JSON
is not supported yet.

## Example

```text
db/p2.sql:1:1: warning HAR4116: The JSON Schema of the parameter lib.save_book.@extra isn't read: haruspex reads one on a table's column only, so it declares nothing here.
```
