# HAR5204: a table type's column can't be declared to the driver

**Error.** Found emitting the database module's functions. It stops the run: nothing is written.

## What it means

A procedure has a table-valued parameter, and a column of its table type has a type the IR gives no driver type for, such as a
number of no known format. A function sends a table-valued parameter as the driver's `sql.Table`, which declares every column's
type, so it can't be written for that procedure.

## Why haruspex reports it

No IR haruspex writes has such a column, but an IR is a file anything can write, so a table type whose columns can't
all be declared is refused rather than written as a function whose every call would fail
([decision 0076](../decisions/0076-a-table-valued-parameter-is-an-array-of-strict-rows-of-its-type.md)).

## What to do

Give the column's type its format in the IR, or generate the IR again with haruspex.

## Example

```text
haruspex: error HAR5204: The function of s.p must declare the column qty of the table type s.lines to the driver, and its type gives no driver type to declare it as.
```
