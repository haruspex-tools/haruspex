# HAR3018: a value declared nullable

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

`"nullable": true`.

## Why haruspex reports it

A value is nullable unless the database proves otherwise, so there is nothing to declare.

## What to do

Remove it.

## Example

```text
haruspex.json:1:147: error HAR3018: procedures["lib.get_book"].paths["[].note"].nullable: can only be false. A value is nullable unless the database proves otherwise, so there is nothing to declare.
```
