# HAR6025: an acknowledgement that matches no warning

**Warning.** Found applying the config file. The run goes on.

## What it means

An entry of the config file's `acknowledge` matched no warning in the run: its cause has gone, or its code or subject is
not what the warning gives.

## Why haruspex reports it

An entry left behind after its cause is gone would quietly hide the next warning of that subject, which may mean something
else. A run whose `--include` narrows the selection doesn't say it, since the warning may be about a procedure the run left
out.

## What to do

Remove the entry, or correct its code or its subject: the subject is the name the warning gives, which
[the configuration](../configuration.md#warnings-acknowledged-acknowledge) lists for each code.

## Example

```text
haruspex.json:1:93: warning HAR6025: acknowledge[0]: acknowledges HAR2101 for "lib.audit", but this run gave no such warning. Remove the entry, or correct its code or its subject: HAR2101's subject is the name the warning gives.
```
