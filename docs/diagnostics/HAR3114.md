# HAR3114: a recursive schema

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A schema that refers to itself.

## Why haruspex reports it

A recursive declared schema isn't supported yet.

## What to do

Declare the value without recursion, or as far as your application needs.

## Example

```text
haruspex.json:1:224: error HAR3114: procedures["lib.p"].results.json.$defs.node.properties.next.$ref: refers to "#/$defs/node" inside itself: a recursive schema is not supported yet.
```
