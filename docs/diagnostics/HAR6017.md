# HAR6017: unknowns the config file fails

**Error.** Found by `haruspex check`, comparing with what is committed. The check fails, with exit code 1, and nothing is
written.

## What it means

The module has unknowns, each a note above it with its reason, and the config file says `"check": { "unknowns": "fail" }`.

## Why haruspex reports it

By default an unknown is a note, and the check passes: an unknown is still checked at runtime as a value of any shape. A
module that must be typed throughout asks for this, so that a new unknown fails the build.

## What to do

Type each unknown: an override of its path, declared results, or a change to the SQL so that haruspex can infer it. Or set
`"unknowns"` to `"report"`.

## Example

```text
haruspex.json: error HAR6017: 1 unknown in the module, each said above, and "check": { "unknowns": "fail" } fails the check on any. Type each (an override, declared results), or set it to "report".
```
