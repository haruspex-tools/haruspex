# HAR6032: --fit-only without a baseline

**Error.** Found by `haruspex check`, settling its baseline. The run stops with exit code 2, and nothing is compared.

## What it means

`--fit-only` asks `check` to judge the module against a baseline alone, without the output folder, but neither `--baseline`
nor the config file's `baseline` names one.

## Why haruspex reports it

Without a baseline there is nothing to judge the module against, and the comparison with the output folder is what
`--fit-only` leaves out. A check that compared nothing and passed would claim what it hadn't shown.

## What to do

Give the baseline with `--baseline`, or in the config file; or leave out `--fit-only` to compare with the output folder.

## Example

```text
haruspex: error HAR6032: --fit-only judges the module against a baseline alone, and none is given. Give --baseline, or "baseline" in the config file; or leave out --fit-only to compare with the output folder.
```
