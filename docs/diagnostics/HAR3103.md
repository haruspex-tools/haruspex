# HAR3103: a rowset's column isn't a scalar

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A rowset's column isn't a scalar.

## Why haruspex reports it

A column holds a string, a number, an integer or a boolean. JSON a column holds is a string.

## What to do

Declare the column as a scalar; for JSON in a column, a string.

## Example

```text
haruspex.json:1:168: error HAR3103: procedures["lib.p"].results.rowset.properties.a: a rowset's column holds a scalar: a string, number, integer or boolean. JSON a column holds is a string.
```
