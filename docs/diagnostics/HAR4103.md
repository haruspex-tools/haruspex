# HAR4103: two overrides of one procedure

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

Two overrides of one procedure, their keys differing only in case or brackets.

## Why haruspex reports it

SQL Server compares names ignoring case, so both name the same procedure, and which wins would be arbitrary.

## What to do

Merge the two.

## Example

```text
haruspex.json:1:130: error HAR4103: procedures["LIB.GET_BOOK"]: lib.get_book already has overrides, at line 1; names are compared ignoring case, as SQL Server compares them. Merge the two.
```
