# HAR3101: a rowset isn't declared by one row's schema

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A declared rowset isn't the schema of one row: an object with `properties`, one for each column.

## Why haruspex reports it

A rowset's rows are objects with the same columns; that is the only shape a row has.

## What to do

Declare the row as an object with `properties`.

## Example

```text
haruspex.json:1:127: error HAR3101: procedures["lib.p"].results.rowset: a rowset is declared by the schema of one row: an object with "properties", one for each column.
```
