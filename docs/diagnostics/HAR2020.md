# HAR2020: a procedure name more than one schema has

**Note.** **Retired.** It was to be found inferring the results; haruspex no longer reports it, and its number is never
given out again.

## What it meant

An unknown whose reason is a call of a procedure whose unqualified name more than one schema has: results only a
declaration in the config file can give.

## Why it is retired

Such an unknown is reported once, by the step that applies the config file, as a warning that says what to declare:
[HAR4204](HAR4204.md) for result sets, [HAR4205](HAR4205.md) for values after a call that isn't followed. A note beside
the warning would say the same fact twice, so this code was retired before it was ever reported.

## What to do

Read the warning it gave way to.

**See also:** [Decision 0036](../decisions/0036-diagnostics-have-stable-codes.md).
