# HAR4109: a name for a value that isn't an object

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

A `name` given at a path whose value isn't an object.

## Why haruspex reports it

Only an object type has a name in the generated code.

## What to do

Name the object: for an array's items, the path ends with `[]`.

## Example

```text
haruspex.json:1:122: error HAR4109: procedures["lib.get_book"].paths["[].title"]: only an object type can be named, and the value at results[0][].title is a string (nvarchar(100)).
```
