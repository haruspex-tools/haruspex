# HAR2014: a temporary table the caller may create

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

A temporary table the procedure reads without creating it on every path: a table of that name the caller created, if
any, so its shape depends on who calls. The value, or the result, is unknown in the output, with this reason, and the
generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Create the table in the procedure, or pass the data another way.

## Example

```text
db/p1.sql:1:34: note HAR2014: lib.p results[0][].id: #caller is not created by the procedure before this, so it is the caller's, whose shape depends on who calls.
```
