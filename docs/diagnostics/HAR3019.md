# HAR3019: a name isn't a valid identifier

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A name the file gives (a procedure's or a type's) or the schema a path imports isn't a valid identifier: an ASCII
letter, `_` or `$`, then letters, digits, `_` or `$`, and not a word the generated code's language reserves.

## Why haruspex reports it

Generated names are identifiers in the generated code; a name that isn't one couldn't be declared.

## What to do

Choose another name.

## Example

```text
haruspex.json:1:119: error HAR3019: procedures["lib.get_book"].name: 'delete' is not a valid name: an ASCII letter, _ or $, then letters, digits, _ or $, and not a reserved word.
```
