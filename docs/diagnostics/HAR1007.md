# HAR1007: a referenced project isn't found

**Warning.** Found reading a project file. The run goes on, and what is written says less.

## What it means

The project being read refers to another project of the same database (a `ProjectReference` naming no other database), and
no file is at the path it gives, even ignoring case.

## Why haruspex reports it

A project of the same database is part of the database. Without it, a table, view, function or procedure it defines is
missing from what haruspex reads, so whatever uses one is unknown; each such unknown says the name may be defined in the
missing project. Saying it once here sends you to the one cause rather than to each name, as [HAR1003](HAR1003.md) does for
a package.

## What to do

Check out the referenced project beside this one, where the path says, or correct the path in the project file.

## Example

```text
db/db.sqlproj:5:15: warning HAR1007: db.sqlproj refers to ..\shelf\shelf.sqlproj, a project of the same database, which isn't found: what it defines is missing.
```
