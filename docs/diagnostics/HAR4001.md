# HAR4001: a schema the project doesn't have

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

A key of `schemas` names no schema that has a procedure in the project.

## Why haruspex reports it

A typo would otherwise drop a schema's procedures from the generated code without anyone noticing.

## What to do

Write the schema's name as it is in the database, without brackets; dots are allowed.

## Example

```text
haruspex.json:1:75: error HAR4001: schemas.shelf: the project has no procedure in a schema named "shelf". A schema key is the schema's name as it is, without brackets.
```
