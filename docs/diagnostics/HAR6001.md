# HAR6001: the command line doesn't parse

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

The command line doesn't parse: an option haruspex doesn't know, or one without its value.

## Why haruspex reports it

A run that guessed what was meant could write somewhere unexpected.

## What to do

Correct the command; `haruspex --help` lists the options.

## Example

```text
haruspex: error HAR6001: Unrecognized command or argument 'blue'.
```
