# HAR6003: no source is given

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

Neither the command line nor a config file says what to read: a folder of `.sql` files, a project file (`.sqlproj`) or a DACPAC.

## Why haruspex reports it

There is nothing to read.

## What to do

Give the folder, project file or DACPAC as the first argument, or `source` in the config file.

## Example

```text
haruspex: error HAR6003: give the folder of .sql files, the .sqlproj or the .dacpac to read, or a config file with "source".
```
