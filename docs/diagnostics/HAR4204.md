# HAR4204: result sets only a declaration can give

**Warning.** Found applying the config file to what was inferred. The run goes ahead, but `haruspex check` fails with
[HAR6016](HAR6016.md) until the results are declared.

## What it means

A selected procedure's result sets can't be known from the project: it runs dynamic SQL, calls a procedure chosen when
it runs, a system procedure, one outside the project, one whose schema depends on the caller's default schema, one created
`WITH ENCRYPTION`, or code outside it. They are unknown in the output, and the
message names the statement.

## Why haruspex reports it

Only you can say what such a procedure returns, and nothing generated checks it until you do. It is a warning, not an
error, so that a run still writes everything else.

## What to do

Declare the results in the config file under `procedures["…"].results`, as `"none"` or a JSON Schema, with `why`; or
declare the results of the procedure it runs.

## Example

```text
haruspex: warning HAR4204: lib.p: its result sets are unknown: EXEC sp_executesql @sql runs dynamic SQL, a string built when the procedure runs, so its result sets are not known. (p1.sql:2:1) Declare them in haruspex.json under procedures["lib.p"].results, as "none" or a JSON Schema, or declare the results of the procedure that runs it.
```
