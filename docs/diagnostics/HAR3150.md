# HAR3150: a format haruspex doesn't check

**Warning.** Found reading the config file. The run goes ahead.

## What it means

A `format` haruspex doesn't check.

## Why haruspex reports it

The generated schema checks only what haruspex can write, so this format is not checked: a value of another format
passes.

## What to do

Remove the format, or check it in your application.

## Example

```text
haruspex.json:1:155: warning HAR3150: procedures["lib.p"].results.json.format: "ipv4" is not a format haruspex checks, so the generated schema does not check it.
```
