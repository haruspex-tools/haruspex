# HAR3111: an array schema without items

**Error.** **Retired.** It was found reading the config file; haruspex no longer reports it, and its number is never given out
again.

## What it meant

An array schema without `items`.

## Why it is retired

A declared array was read by its items' schema, and this one gave none. Such a schema is read as an array of any JSON, which is what it allows ([decision 0094](../decisions/0094-any-json-is-a-type-of-its-own.md)). Reading it so is wider than refusing it, never narrower, so a value the schema allows is still accepted.

## What to do

Nothing: the declaration is read as it is.

**See also:** [Decision 0036](../decisions/0036-diagnostics-have-stable-codes.md), [the configuration reference](../configuration.md).
