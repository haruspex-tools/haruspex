# HAR3111: an array schema without items

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

An array schema without `items`.

## Why haruspex reports it

Nothing says what the array holds.

## What to do

Give `items`, the schema of the items.

## Example

```text
haruspex.json:1:125: error HAR3111: procedures["lib.p"].results.json: needs "items", the schema of its items.
```
