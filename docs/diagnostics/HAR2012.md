# HAR2012: recursion that reached no fixed point

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

Functions that call themselves, directly or through others, whose shape reached no fixed point in the passes haruspex
allows, or that never return. The value, or the result, is unknown in the output, with this reason, and the generated
schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Check that the recursion ends; a shape that keeps growing is one no finite type describes.

## Example

```text
db/p1.sql:1:1: note HAR2012: lib.p results[0][].v: Every return of lib.again calls itself again, so it never returns a value.
```
