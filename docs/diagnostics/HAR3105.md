# HAR3105: a schema without a type

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A schema whose only type is `null`, or the schema `false`. A schema without a `type` is any JSON, which is read.

## Why haruspex reports it

A value that is only ever null, or that can be nothing at all, is no type a result or a column can hold.

## What to do

Give the schema a `type` besides `null`; for a value that may be anything, write `{}`.

## Example

```text
haruspex.json:1:166: error HAR3105: procedures["lib.p"].results.json.properties.a: needs a type other than "null".
```
