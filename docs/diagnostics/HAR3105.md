# HAR3105: a schema without a type

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A schema without a `type`, or whose only type is `null`.

## Why haruspex reports it

A declared schema is read by its type; without one, nothing says what the value is.

## What to do

Give the schema a `type`.

## Example

```text
haruspex.json:1:166: error HAR3105: procedures["lib.p"].results.json.properties.a: needs a "type".
```
