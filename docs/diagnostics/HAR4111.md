# HAR4111: exact values the inference already proves

**Warning.** Found applying the config file to what was inferred. The run goes ahead.

## What it means

`"values": "exact"` where haruspex already proves the set exact.

## Why haruspex reports it

The file shrinks as the SQL improves.

## What to do

Remove it.

## Example

```text
haruspex.json:1:122: warning HAR4111: procedures["lib.get_book"].paths["[].copies"]: "values": "exact" agrees with the inference, which already proves the set at results[0][].copies exact. Remove it.
```
