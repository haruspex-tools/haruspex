# HAR4005: an --include matches nothing

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

An `--include` on the command line matches no procedure.

## Why haruspex reports it

A run that types less than asked, without a word, would hide a typo.

## What to do

Correct the pattern (`schema.name`, `*` and `?` within a part), or remove it.

## Example

```text
haruspex: error HAR4005: --include 'lib.list_*' matches no procedure. Correct it, or remove it.
```
