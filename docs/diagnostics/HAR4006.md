# HAR4006: an --include selects only excluded procedures

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

An `--include` matches only procedures the config file's excludes leave out.

## Why haruspex reports it

A schema's exclude still applies to a run's includes, so the pattern selects nothing.

## What to do

Change the pattern, or the exclude.

## Example

```text
haruspex: error HAR4006: --include 'lib.get_book' matches only procedures that schemas.lib.exclude leaves out, so it selects nothing.
```
