# HAR4002: an include matches nothing

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

An `include` pattern selects no procedure in its schema.

## Why haruspex reports it

A typo would otherwise drop an interface from the generated code without anyone noticing.

## What to do

Correct the pattern, or remove it.

## Example

```text
haruspex.json:1:76: error HAR4002: schemas.lib.include[1]: 'list_*' matches no procedure in the schema "lib". Correct it, or remove it.
```
