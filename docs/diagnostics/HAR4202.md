# HAR4202: declared results the inference already gives

**Warning.** Found applying the config file to what was inferred. The run goes ahead.

## What it means

Declared results that agree with what haruspex infers.

## Why haruspex reports it

The file shrinks as the SQL improves: a declaration the inference agrees with can go.

## What to do

Remove the declaration.

## Example

```text
haruspex.json:1:93: warning HAR4202: procedures["lib.count_books"]: the declared results agree with the inference, which already infers the results of lib.count_books. Remove the declaration.
```
