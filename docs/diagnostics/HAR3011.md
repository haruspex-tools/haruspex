# HAR3011: a claim without why

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A claim without `why`: declared `results`, `"nullable": false` or `"values": "exact"`.

## Why haruspex reports it

Each is something the database doesn't prove, so the file says what does. The reason is written to the IR beside the
claim, where a reader can weigh it.

## What to do

Add `why`, saying what makes the claim true.

## Example

```text
haruspex.json:1:133: error HAR3011: procedures["lib.get_book"].paths["[].note"]: "nullable": false needs "why": the database doesn't prove it, so say what does.
```
