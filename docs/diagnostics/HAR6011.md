# HAR6011: nothing committed to check against

**Error.** Found by `haruspex check`, comparing with what is committed. The check fails, with exit code 1, and nothing is
written.

## What it means

`haruspex check` found no committed IR, no committed module, or neither, in the output folder (`out` in the config file,
or `--out`). The message names each file that isn't there.

## Why haruspex reports it

`check` compares what haruspex would write with what is committed. With nothing committed, there is nothing to compare, and
passing would let a module that was never generated, or an `out` that names the wrong folder, through CI without a word.

## What to do

If the module is new, run `haruspex generate`, read what it writes, and commit both files. If they are committed, check that
`out` names the folder they are in.

## Example

```text
haruspex: error HAR6011: nothing to compare with: out/haruspex.ir.json and out/haruspex.zod.ts aren't there. Run haruspex generate, read what it writes, and commit it.
```
