# HAR6002: the config file isn't there

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

The config file `--config` names isn't there.

## Why haruspex reports it

A run without the settings asked for would generate something else.

## What to do

Correct the path; it is relative to the working directory.

## Example

```text
haruspex: error HAR6002: config file not found: nowhere.json
```
