# HAR2105: declared result sets the callee never returns

**Warning.** Found inferring the results. The run goes ahead.

## What it means

An `EXEC … WITH RESULT SETS` declares result sets that the callee, a procedure of the project, never returns: another number of
sets than any path of it returns (`NONE` over a callee that always returns one included), or a set of another number of
columns than every set it may return there.

## Why haruspex reports it

The server holds a call to its declaration, and fails it when the callee returns another number of sets (11535, 11536) or a
set of another width (11537), even with no rows. So every call fails, and haruspex follows no path past it: the results after
it are those of the paths that don't make the call.

## What to do

Declare the sets the callee returns, in order, each with as many columns as the callee's; or, if the callee changed, change
the declaration with it.

## Example

```text
db/p2.sql:1:27: warning HAR2105: EXEC lib.q WITH RESULT SETS declares 2 result sets, but lib.q returns 1, so every call fails (11536). Declare the sets it returns.
```
