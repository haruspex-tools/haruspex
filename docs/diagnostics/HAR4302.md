# HAR4302: a type that can't be named

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

A type a function builds that the naming rules can't name.

## Why haruspex reports it

Generated names are identifiers in the generated code.

## What to do

Change the naming rules the message points at.

## Example

```text
haruspex.json:1:87: error HAR4302: naming: the recursive function lib.tree#'s type cannot be named: "case": "preserve" gives 'tree#', which is not a valid identifier (an ASCII letter, _ or $, then letters, digits, _ or $). Add a replacement, or give it a name in "procedures". Change the naming rules so that they name it.
```
