# HAR3022: a queries entry outside the config file's folder

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

An entry of `queries` reaches outside the folder of the config file: it starts at the root, or goes up with `..`.

## Why haruspex reports it

A query file belongs to the module whose config file's folder holds it, so that each file has one module and two modules never
generate a function for one file. A file above the config file is another module's, or none's.

## What to do

Move the query files below the config file's folder, or give the folder that holds them a `haruspex.json` of its own.

## Example

```text
haruspex.json:1:88: error HAR3022: queries: "../shared/sql" reaches outside the folder of the config file; a query file belongs to the module whose folder holds it, so name only files below this one.
```
