# HAR5004: an imported name the module also declares

**Error.** Found emitting the Zod module. It stops the run: nothing is written.

## What it means

An imported name is one the generated module also declares or uses.

## Why haruspex reports it

The two declarations would clash.

## What to do

Import the schema under another name.

## Example

```text
haruspex.json: error HAR5004: The imported name 'z' is also a name this module defines or uses.
```
