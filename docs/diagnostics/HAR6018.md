# HAR6018: no config file below the folder

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

`--all` asks for every `haruspex.json` below a folder, the working directory or the one given, and there is none there, or
the folder isn't there. Folders whose name starts with a dot, and `node_modules`, aren't looked in.

## Why haruspex reports it

A run over every module that finds none would pass without checking anything, which in CI would hide a wrong folder.

## What to do

Give the folder that holds the modules' config files: `--all apps` when they are under `apps`. To run one module, use
`--config` or no option.

## Example

```text
haruspex: error HAR6018: --all: no haruspex.json below db. Give the folder that holds the modules' config files.
```
