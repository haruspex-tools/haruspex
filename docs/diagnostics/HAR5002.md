# HAR5002: an imported name isn't a TypeScript identifier

**Error.** Found emitting the Zod module. It stops the run: nothing is written.

## What it means

An imported schema's name isn't a TypeScript identifier.

## Why haruspex reports it

An import of it couldn't be written.

## What to do

Correct `type` in the path override that imports it.

## Example

```text
haruspex: error HAR5002: The imported name 'class' is not a valid TypeScript identifier.
```
