# HAR3108: an object schema without properties

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

An object schema without `properties` or `additionalProperties`.

## Why haruspex reports it

Without either, nothing says what the object holds.

## What to do

Give `properties`, its keys, or `additionalProperties`, the type of every value of an object whose keys are data.

## Example

```text
haruspex.json:1:125: error HAR3108: procedures["lib.p"].results.json: needs "properties" (its keys), or "additionalProperties" (the type of every value, for an object whose keys are data).
```
