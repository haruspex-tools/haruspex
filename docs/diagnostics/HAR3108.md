# HAR3108: an object schema without properties

**Error.** **Retired.** It was found reading the config file; haruspex no longer reports it, and its number is never given out
again.

## What it meant

An object schema with neither `properties` nor `additionalProperties`.

## Why it is retired

A declared object was read by its keys, and this one listed none. Such a schema is read as an object whose keys are data, every value any JSON, which is what it allows ([decision 0094](../decisions/0094-any-json-is-a-type-of-its-own.md)); with `additionalProperties: false`, as an object with no keys. Reading it so is wider than refusing it, never narrower, so a value the schema allows is still accepted.

## What to do

Nothing: the declaration is read as it is.

**See also:** [Decision 0036](../decisions/0036-diagnostics-have-stable-codes.md), [the configuration reference](../configuration.md).
