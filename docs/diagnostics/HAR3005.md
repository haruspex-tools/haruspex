# HAR3005: a value of the wrong kind

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A setting's value is of the wrong kind: a number where a string goes, an empty list where one is needed, a word that
isn't one of the setting's choices, or a `collation` SQL Server doesn't have or that no database can have. The message says what the value must be.

## Why haruspex reports it

A value haruspex can't read would otherwise be ignored or guessed at.

## What to do

Give the value the message asks for. Naming the published JSON Schema in `$schema` lets an editor check this as you
type.

## Example

```text
haruspex.json:1:88: error HAR3005: objects: must be "strip" or "strict", not "loose".
```
