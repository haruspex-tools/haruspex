# HAR6004: the source isn't there

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

The folder of `.sql` files, or the `.dacpac`, that the command line or `source` names isn't there.

## Why haruspex reports it

There is nothing to read.

## What to do

Correct the path.

## Example

```text
haruspex: error HAR6004: directory not found: nowhere
```
