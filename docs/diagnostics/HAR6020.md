# HAR6020: two modules write to one folder

**Error.** Found on the command line, or reading and writing files. It stops the run: nothing is written.

## What it means

Two of the modules a run covers (`--all`, or more than one `--config`) have the same output folder, `out` in their config
files. The message names both config files and the folder.

## Why haruspex reports it

Each module writes its own `haruspex.ir.json` and `haruspex.zod.ts`. Two in one folder would overwrite each other under
`generate`, the second winning without a word, and `check` would compare both modules with one pair of files.

## What to do

Give each module its own `out`, such as a folder beside its config file.

## Example

```text
haruspex: error HAR6020: a/haruspex.json and b/haruspex.json both write to out, so one module would overwrite the other's. Give each module its own "out".
```
