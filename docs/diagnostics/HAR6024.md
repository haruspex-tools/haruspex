# HAR6024: a code that can't be acknowledged

**Error.** Found reading the config file. It stops the run: nothing is written, and the exit code is 2.

## What it means

An entry of the config file's `acknowledge` names a code that can't be acknowledged: an error, a note, or a warning that
names no subject, such as one about the config file itself.

## Why haruspex reports it

Acknowledging a warning says it has been read and is lived with. An error stops the run and must be fixed; a warning about
the config file is fixed in the file. Only the warnings about the source that name a subject can be acknowledged: HAR1003,
HAR1007, HAR1008 for a build target, and HAR2101.

## What to do

Fix what the code says, and remove the entry.

## Example

```text
haruspex.json:1:93: error HAR6024: acknowledge[0]: HAR1001 can't be acknowledged: only a warning about the source that names its subject can be, and those are HAR1003, HAR1007, HAR1008, HAR2101. Fix what HAR1001 says instead.
```
