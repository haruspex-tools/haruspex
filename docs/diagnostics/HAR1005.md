# HAR1005: a file that can't be read as a DACPAC

**Error.** Found reading a DACPAC. It stops the run: nothing is written.

## What it means

A file given as the source, or found for a reference, is not a DACPAC: it isn't a zip, or holds no `model.xml` with a
model, or its XML doesn't read. Nothing in it is read.

## Why haruspex reports it

A model built without the package would be missing everything it defines.

## What to do

Check the file is the DACPAC a build or SqlPackage wrote, whole: rebuild the project, or copy it again.

## Example

```text
broken.dacpac: error HAR1005: broken.dacpac can't be read as a DACPAC: Central Directory corrupt.
```
