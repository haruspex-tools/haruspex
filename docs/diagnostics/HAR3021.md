# HAR3021: a references folder isn't there

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A folder that `references` lists, to look for a DACPAC's referenced packages in, doesn't exist (relative to the config file).

## Why haruspex reports it

A misspelt folder would otherwise show only as a referenced DACPAC not found ([HAR1003](HAR1003.md)), which blames the
package rather than the setting.

## What to do

Correct the path, or remove it if the packages are now beside the one that refers to them.

## Example

```text
haruspex.json:1:92: error HAR3021: references[0]: "no/such/folder" is not a folder, so no referenced DACPAC can be found in it.
```
