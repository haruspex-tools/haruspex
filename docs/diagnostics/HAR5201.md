# HAR5201: a procedure's function can't take its name

**Error.** Found emitting the database module's functions. It stops the run: nothing is written.

## What it means

A procedure's function is named for it, with a lower-case first word (`GetOrder` is `getOrder`), and that name is a word
TypeScript reserves, a name the module uses for itself (such as `readJson` or `sql`), a schema the module imports, or the
function of another procedure.

## Why haruspex reports it

A module can't bind one name twice, and haruspex never renames anything on its own, so that adding a procedure can't change
an existing function's name.

## What to do

Give the procedure another name in the config file, with a `name` override or a naming rule.

## Example

```text
haruspex: error HAR5201: The function of shop.delete would be named delete, which is a reserved word; rename the procedure in the config file.
```
