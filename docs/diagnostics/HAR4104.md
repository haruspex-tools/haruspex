# HAR4104: a path that doesn't exist

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

A path override's path doesn't exist in the procedure's results: a key the object hasn't got, a result set it doesn't
return, or a step through a value that has no such part. The message lists what is there.

## Why haruspex reports it

An override whose path is wrong would do nothing, silently; one whose path has gone stale must shrink the file.

## What to do

Correct the path, starting with `results[n]` when the procedure returns more than one result set, or remove the
override.

## Example

```text
haruspex.json:1:122: error HAR4104: procedures["lib.get_book"].paths["[].nope"]: the path results[0][].nope does not exist: the object at results[0][] has no key "nope". Its keys are "id", "title", "note", "status", "copies", "extra".
```
