# HAR3010: a regular expression haruspex can't use

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A naming replacement's `pattern` isn't a regular expression haruspex can use. Patterns are matched without backtracking,
so that a name's matching stays linear in its length: backreferences and lookarounds aren't available.

## Why haruspex reports it

A replacement that can't run can't name anything.

## What to do

Correct the regular expression, without backreferences or lookarounds.

## Example

```text
haruspex.json:1:114: error HAR3010: naming.replace[0].pattern: is not a regular expression haruspex can use: Invalid pattern '(' at offset 1. Not enough )'s.
```
