# HAR3152: a keyword ignored beside a reference

**Warning.** Found reading the config file. The run goes ahead.

## What it means

A keyword beside `$ref`.

## Why haruspex reports it

A reference stands for its definition; JSON Schema ignores what is beside it, and so does haruspex.

## What to do

Move the keyword into the definition, or remove it.

## Example

```text
haruspex.json:1:148: warning HAR3152: procedures["lib.p"].results.json.type: is ignored beside "$ref".
```
