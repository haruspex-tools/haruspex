# HAR6009: references with a source that isn't a DACPAC

**Warning.** Found on the command line, or reading and writing files. The run goes on.

## What it means

The config file lists `references`, folders to find a DACPAC's referenced packages in, but the source read is a folder of
`.sql` scripts, which has no references.

## Why haruspex reports it

The setting does nothing for this run, so it was probably meant for a `.dacpac` source, or is left over from one.

## What to do

Name the `.dacpac` as the source, or remove `references`.

## Example

```text
haruspex.json: warning HAR6009: "references" is read only when the source is a .dacpac, and db is a folder of scripts.
```
