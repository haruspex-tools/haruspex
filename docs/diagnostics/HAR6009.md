# HAR6009: references with a folder of scripts

**Warning.** Found on the command line, or reading and writing files. The run goes on.

## What it means

The config file lists `references`, folders to find a referenced DACPAC in, but the source read is a folder of `.sql` scripts,
which refers to nothing.

## Why haruspex reports it

The setting does nothing for this run, so it was probably meant for a `.dacpac` or `.sqlproj` source, or is left over from one.

## What to do

Name the `.dacpac` or the `.sqlproj` as the source, or remove `references`.

## Example

```text
haruspex.json: warning HAR6009: "references" is read only when the source is a .dacpac or a .sqlproj, and db is a folder of scripts.
```
