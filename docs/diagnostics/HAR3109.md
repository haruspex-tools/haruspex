# HAR3109: a required key that isn't a property

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A `required` key that isn't in `properties`.

## Why haruspex reports it

A key required but not described has no type.

## What to do

Add the key to `properties`, or remove it from `required`.

## Example

```text
haruspex.json:1:204: error HAR3109: procedures["lib.p"].results.json.required: names "b", which is not in "properties".
```
