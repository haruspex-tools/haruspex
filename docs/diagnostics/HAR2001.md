# HAR2001: a statement that isn't modelled yet

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

A statement haruspex doesn't model yet, which may return result sets of its own. The value, or the result, is unknown in
the output, with this reason, and the generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Rewrite the statement with constructs haruspex models, if you can; otherwise the procedure's results stay unknown until
haruspex models it.

## Example

```text
db/p1.sql:1:27: note HAR2001: lib.p results: SET is not modelled yet, so the procedure's result sets cannot be listed.
```
