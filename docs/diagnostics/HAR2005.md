# HAR2005: an expression that isn't modelled yet

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

An expression or a function haruspex doesn't model yet. The value, or the result, is unknown in the output, with this
reason, and the generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Rewrite the expression, if you can, or override the value's type in the config file (`paths`, `type` and `import`).

## Example

```text
db/p1.sql:1:34: note HAR2005: lib.p results[0][].c: The multi-part column reference lib.book.id is not modelled yet.
```
