# HAR4101: an override of a procedure the project doesn't have

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

An override of a procedure the project doesn't have.

## Why haruspex reports it

An override of nothing is a typo, or stale.

## What to do

Correct the procedure's name, or remove the override.

## Example

```text
haruspex.json:1:93: error HAR4101: procedures["lib.lost_book"]: there is no procedure lib.lost_book in the project.
```
