# HAR4201: declared results disagree with the inference

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

Declared results of a procedure whose results haruspex infers, which disagree with what it infers. The message says
where they first differ.

## Why haruspex reports it

A declaration is for results the project can't show; where haruspex can see them, the declaration is checked, and one
that says something else is wrong somewhere.

## What to do

Correct the declaration, or remove it and correct the inferred results with path overrides.

## Example

```text
haruspex.json:1:93: error HAR4201: procedures["lib.get_book"]: haruspex infers the results of lib.get_book, and the declaration disagrees at results: the inference says 1 result set, the declaration 0. A declaration is for results that can't be inferred; to correct inferred results, override a path under "paths".
```
