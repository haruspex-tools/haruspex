# HAR4304: a name the naming rules already give

**Warning.** Found applying the config file to what was inferred. The run goes ahead.

## What it means

A `name` the naming rules already give.

## Why haruspex reports it

The file shrinks: an override that changes nothing can go.

## What to do

Remove it.

## Example

```text
haruspex.json:1:119: warning HAR4304: procedures["lib.get_book"].name: the name "GetBook" is what the naming rules give lib.get_book already. Remove it.
```
