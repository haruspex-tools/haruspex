# HAR4009: a module comment where the output isn't split

**Warning.** Found applying the config file to the query files. The run goes ahead.

## What it means

A query file has a `-- @module` comment, and the config file has no `split`, so the output is one module and the comment does
nothing.

## Why haruspex reports it

A comment that says where the file goes, and is ignored, misleads the next reader; most likely `split` was removed, or the file
was copied from a project that splits its output
([decision 0074](../decisions/0074-a-config-may-split-its-output-into-modules.md)).

## What to do

Add `split` to the config file, or remove the comment.

## Example

```text
sql/q.sql:1:1: warning HAR4009: -- @module loans: the config file doesn't split its output into modules, so the comment does nothing. Add "split" to the config file, or remove the comment.
```
