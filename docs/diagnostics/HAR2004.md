# HAR2004: a query form that isn't modelled yet

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

A form of query haruspex doesn't model yet. The value, or the result, is unknown in the output, with this reason, and
the generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Rewrite the query with forms haruspex models, if you can, or override the value's type in the config file.

## Example

```text
db/p1.sql:1:58: note HAR2004: lib.p results[0]: FOR JSON AUTO is not modelled yet.
```
