# HAR6021: a config file is already there

**Error.** Found by `haruspex init`. Nothing is written, and the exit code is 2.

## What it means

`haruspex init` was run in a folder that already holds a `haruspex.json`.

## Why haruspex reports it

`init` writes a starter config file for a project that has none. One that is there may hold settings that took work to get
right, and a starter would lose them, so `init` never writes over one, whatever is in it.

## What to do

Edit the config file that is there; [the configuration](../configuration.md) describes each setting. To start again, remove
it, or move it aside, and run `haruspex init` again.

## Example

```text
haruspex.json: error HAR6021: a config file is already here, and init doesn't write over one. Edit it, or remove it to start again.
```
