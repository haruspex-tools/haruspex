# HAR4203: declared results nothing uses

**Warning.** Found applying the config file to what was inferred. The run goes ahead.

## What it means

Declared results of a procedure that isn't selected and that no selected procedure calls.

## Why haruspex reports it

A declaration that does nothing is stale or misplaced.

## What to do

Remove it, or select the procedure.

## Example

```text
haruspex.json:1:93: warning HAR4203: procedures["other.thing"]: the declared results are not used: other.thing is not selected, and no selected procedure calls it.
```
