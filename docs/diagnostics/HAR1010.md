# HAR1010: a file that can't be read as a database project

**Error.** Found reading a project file. Nothing in it is read.

## What it means

The file given or referred to as a `.sqlproj` isn't a database project haruspex reads: it isn't MSBuild XML, or it uses an SDK
other than `Microsoft.Build.Sql` (such as the community `MSBuild.Sdk.SqlProj`), whose build reads other scripts by other
rules.

## Why haruspex reports it

Which scripts a `Microsoft.Build.Sql` project and a legacy SSDT project build, and with which settings, is known and proved;
for another SDK it would be a guess.

## What to do

Read the DACPAC the project builds, or the folder of its scripts with `collation` in the config file.

## Example

```text
db/db.sqlproj:1:2: error HAR1010: db.sqlproj uses the SDK MSBuild.Sdk.SqlProj/3.0.0, which haruspex doesn't read: it reads Microsoft.Build.Sql projects and legacy SSDT ones.
```
