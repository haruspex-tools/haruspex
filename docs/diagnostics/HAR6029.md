# HAR6029: the baseline isn't there

**Error.** Found by `haruspex check` or `haruspex generate`, settling its baseline. The run stops with exit code 2.

## What it means

The baseline that `--baseline` or the config file's `baseline` names is neither a file nor a folder.

## Why haruspex reports it

A baseline is never fetched: haruspex doesn't run git or download a release's DACPAC. A step before it, usually in CI, puts the
baseline where the command line or the config file says, so a baseline that isn't there is a step that didn't run or a path
written wrong.

## What to do

Put the baseline there first, as [the recipes](../command-line.md#checking-against-a-baseline) do, or correct the path.

## Example

```text
haruspex: error HAR6029: the baseline release/Library.dacpac isn't there. haruspex never fetches it: put it there first (in CI, a step before this one), or correct --baseline or "baseline".
```
