# HAR4008: an object in no module

**Error.** Found applying the config file's `split` to the selected procedures and query files. It stops the run: nothing is
written.

## What it means

The config file lists its modules, and a selected procedure's schema is in none of their lists; or a query file's
`-- @module` comment names a module the config file doesn't have.

## Why haruspex reports it

Every selected procedure and query file is written to some module's files. Putting one in a module nobody listed, or leaving it
out, would write an interface nobody chose to where nobody looks for it, or drop it without a word
([decision 0074](../decisions/0074-a-config-may-split-its-output-into-modules.md)).

## What to do

Add the schema to a module's list, or leave the procedure out of the selection. For a query file, name one of the modules the
message lists. A module of query files alone is listed with no schemas: `"reports": []`.

## Example

```text
haruspex.json:1:86: error HAR4008: split: the procedure lib.get_book is in no module: no module lists its schema, lib. Add the schema to a module's list, or leave the procedure out of the selection.
```
