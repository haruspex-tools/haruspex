# HAR4105: a path through a value of several types

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

A path that passes through a value of several types.

## Why haruspex reports it

A path can't choose between the types of a union.

## What to do

Override the value at the union itself, or change the SQL so that it has one type.

## Example

```text
haruspex.json:1:122: error HAR4105: procedures["lib.get_book"].paths["[].u<json>[].a"]: the path results[0][].u<json>[].a passes through a value of several types at results[0][].u<json>[], and a path can't choose between them.
```
