# HAR2021: a trigger that may return result sets

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

A statement fires a trigger of the project that may return result sets, which arrive among the procedure's. The value,
or the result, is unknown in the output, with this reason, and the generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Make the trigger return nothing (set its `SELECT`s into variables, or remove them).

## Example

```text
db/p2.sql:1:27: note HAR2021: lib.p results: The write at p2.sql:1:27 fires the trigger lib.book_seen on lib.book (p1.sql:1:1), which returns a result set at p1.sql:1:58
```
