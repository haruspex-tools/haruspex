# HAR4113: a column that can't hold declared JSON

**Error.** Found applying the config file to the project. It stops the run: nothing is written.

## What it means

A column `columns` declares to hold JSON of a schema is not one that can: it isn't in the project, it is computed, it is of a
type that can't hold text (only `char`, `varchar`, `nchar`, `nvarchar`, an alias type of one, and `json` can), or it is a
view's column.

## Why haruspex reports it

A declaration completes a table column's type, which is read wherever the column is read. A view's column holds what it reads,
so it gets the declaration from the table column it reads; declared itself, it could disagree with that column's.

## What to do

Declare the table column the message names, correct the column's name, or remove the declaration.

## Example

```text
haruspex.json:1:90: error HAR4113: columns["lib.book.copies"]: lib.book.copies is of the type int, which can't hold JSON text: only a string type (char, varchar, nchar, nvarchar) or json can.
```
