# HAR6036: a combined IR given as a database

**Error.** Found by `haruspex generate` with a baseline, and by `haruspex check` with one (unless `--fit-only`). The run stops
with exit code 1, and nothing is written.

## What it means

The baseline is an IR file that `haruspex generate` wrote with a baseline of its own (whose `source` names a
`baseline`). Such a file says what an application built against two databases accepts, which is wider in its results and
narrower in its parameters than either database, not what one database is.

## Why haruspex reports it

Combining with it would still be sound, but loose: its widened results would never tighten again as releases go by, and a
parameter it leaves out would be reported as new when it isn't. The baseline for combined types is the database the application
meets before the change.

## What to do

Give the baseline as that database's source (a `.dacpac`, a `.sqlproj` or a folder), or as an IR file written without a baseline.
A combined IR is the right baseline for `haruspex check --fit-only`, which asks whether a database fits an application already
running, as a database's pipeline does with each application's committed IR.

## Example

```text
haruspex: error HAR6036: the baseline release.ir.json is a combined IR, written with a baseline of its own: it says what an application built against two databases accepts, not what one database is. Give the database the application meets before the change, as its source (a .dacpac, a .sqlproj or a folder) or an IR written without a baseline. A combined IR is a baseline for check --fit-only only, which asks whether a database fits an application.
```
