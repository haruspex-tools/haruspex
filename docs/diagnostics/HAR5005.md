# HAR5005: a type read both as rows and as JSON

**Error.** Found emitting the Zod module. It stops the run: nothing is written.

## What it means

A named type that one result reads as rows and another as JSON.

## Why haruspex reports it

Scalars arrive differently in each (a date is a string in JSON and a `Date` in a row), so one schema can't check both.
The front end never makes such a type, so this comes from an IR file written by something else.

## What to do

Give each encoding its own type in the IR, or generate the IR with haruspex.

## Example

```text
haruspex: error HAR5005: The type Shared is read both as rows and as JSON, so one schema can't check it.
```
