# HAR3004: an unknown setting

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A key in the file isn't a setting haruspex knows at that place. The message lists the settings there.

## Why haruspex reports it

A misspelt setting would otherwise do nothing, silently: the run would go ahead without it.

## What to do

Correct the key's spelling, or move it to where it belongs.

## Example

```text
haruspex.json:1:77: error HAR3004: colour: unknown setting "colour". The settings here are $schema, source, baseline, references, collation, queries, out, schemas, objects, emit, serverOnly, naming, procedures, session, check, acknowledge.
```
