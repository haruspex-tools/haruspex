# HAR2007: a SQL type that isn't modelled yet

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

A SQL type haruspex doesn't model yet. The value, or the result, is unknown in the output, with this reason, and the
generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Convert the value to a type haruspex models, if the application allows it.

## Example

```text
db/tables.sql:8:5: note HAR2007: lib.p results[0][].cover: The type sql_variant is not modelled yet.
```
