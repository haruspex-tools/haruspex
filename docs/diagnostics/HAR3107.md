# HAR3107: not a JSON Schema type

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A `type` that JSON Schema doesn't have.

## Why haruspex reports it

There is no such type to check.

## What to do

Use `string`, `integer`, `number`, `boolean`, `object`, `array` or `null`.

## Example

```text
haruspex.json:1:135: error HAR3107: procedures["lib.p"].results.json.type: "date" is not a JSON Schema type: use string, integer, number, boolean, object, array or null.
```
