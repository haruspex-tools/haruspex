# HAR6038: nothing of that name to explain

**Error.** Found by `haruspex explain`. Nothing is printed but the error, with exit code 2.

## What it means

The IR has no object, type, field or parameter of the name given: a procedure is named as `schema.name`, a query file by its
path, a generated type by its name; a field by its path in the object's results (`lines[].qty`, a named set's first:
`summary.total`, or by place: `#2.total`), and a parameter with its `@`.

## Why haruspex reports it

A name that matches nothing may be a typo, or a field of another version of the procedure, so `explain` says what the object
does have rather than guessing which was meant.

## What to do

Use one of the names the message lists. `haruspex explain` with the object alone lists each field that differs from what its
columns declare.

## Example

```text
haruspex: error HAR6038: lib.get_book has no field nothing; its fields are id, title, note, status, copies and extra.
```
