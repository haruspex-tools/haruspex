# HAR3017: a path isn't well formed

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A path override's path isn't well formed. The message says where in the path.

## Why haruspex reports it

A path that can't be read leads nowhere.

## What to do

Correct the path: keys separated by `.`, `[]` for an array's items, `[n]` for a position, `<json>` into JSON text.

## Example

```text
haruspex.json:1:122: error HAR3017: procedures["lib.get_book"].paths["a..b"]: 'a..b' is not a path: at 1, a '.' must be followed by a key; write a key that is not an identifier as ["key"].
```
