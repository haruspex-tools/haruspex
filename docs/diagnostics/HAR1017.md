# HAR1017: a query file returns a value

**Error.** Found reading the SQL. It stops the run: nothing is written.

## What it means

A query file has a `RETURN` with a value, such as `RETURN 5`, at any depth. A query file runs as a batch through
`sp_executesql`, where SQL Server allows `RETURN` alone but refuses `RETURN` with a value (error 178), so every call of its
function would fail.

## Why haruspex reports it

The file can't run as it is written, and that is found before any call is made rather than on each one.

## What to do

Write `RETURN` alone to end the batch early. A query that must hand back a code belongs in a procedure, whose function returns
the code beside its result.

## Example

```text
sql/q.sql:1:18: error HAR1017: a batch run through sp_executesql may RETURN, but SQL Server refuses RETURN with a value there (error 178), so every call would fail; write RETURN alone.
```
