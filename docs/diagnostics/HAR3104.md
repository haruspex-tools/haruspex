# HAR3104: a JSON document declared nullable

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A JSON result's document is declared nullable.

## Why haruspex reports it

`FOR JSON` never returns a null document: over no rows it returns none, which `mayBeAbsent` says.

## What to do

Remove `null` from the document's type; use `"mayBeAbsent": true` if the query may match no rows.

## Example

```text
haruspex.json:1:125: error HAR3104: procedures["lib.p"].results.json: the JSON document itself is never null; when a query may match no rows, use "mayBeAbsent": true.
```
