# HAR5001: an IR name isn't a TypeScript identifier

**Error.** Found emitting the Zod module. It stops the run: nothing is written.

## What it means

A name in the IR isn't a TypeScript identifier, or is a word TypeScript reserves.

## Why haruspex reports it

The names haruspex settles are always identifiers, so this comes from an IR file written by something else.

## What to do

Correct the name in the IR, or generate the IR with haruspex.

## Example

```text
haruspex: error HAR5001: The IR name 'string' is not a valid TypeScript identifier.
```
