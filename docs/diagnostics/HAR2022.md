# HAR2022: a result set with a hidden column

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

A result set carries a column the server marks hidden, which some drivers list and others don't, so its keys depend on
the client: `FETCH` without `INTO`. The value, or the result, is unknown in the output, with this reason, and the
generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Fetch `INTO` variables, and select them.

## Example

```text
db/p1.sql:1:94: note HAR2022: lib.p results: FETCH without INTO at p1.sql:1:94 returns the row with a hidden ROWSTAT column, which some drivers list among its columns and others leave out.
```
