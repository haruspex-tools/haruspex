# HAR3001: a config file can't be read

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

The config file, or a schema file it or the SQL names (by the extended property `haruspex.jsonSchema`), can't be read: it is
missing, it is a folder, or you lack permission to read it.

## Why haruspex reports it

Without the file there are no settings to apply, so nothing is generated.

## What to do

Make the file readable, or name another.

## Example

The message ends with what the operating system said, which differs from one to another.

```text
haruspex.json:1:134: error HAR3001: procedures["lib.get_book"].results.rowset: cannot read the schema schemas: …
```
