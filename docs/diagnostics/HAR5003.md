# HAR5003: a name is imported from two modules

**Error.** Found emitting the Zod module. It stops the run: nothing is written.

## What it means

One name is imported from two modules.

## Why haruspex reports it

A module can't bind one name twice.

## What to do

Import the schema from one module, or give the two different names.

## Example

```text
haruspex.json: error HAR5003: 'TextSchema' is imported from both '../a' and '../b'.
```
