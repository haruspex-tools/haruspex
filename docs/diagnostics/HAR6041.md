# HAR6041: a file no longer written can't be removed

**Warning.** Found by `haruspex generate`, removing the files the last run wrote that this one doesn't. The run goes on.

## What it means

The list of the files the last run wrote names this file, this run doesn't write it, and the file system refused to remove it:
it is read-only, or its folder is, or another process holds it open. It stays on the list, so the next run tries again.

## Why haruspex reports it

The file no longer matches the IR, and an application that still imports it compiles against a module that is gone.

## What to do

Remove the file yourself, or fix what stops it being removed and run `haruspex generate` again.

## Example

```text
out/held/old.zod.ts: warning HAR6041: the last run wrote this file and this one doesn't, but it can't be removed: …
```
