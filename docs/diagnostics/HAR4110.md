# HAR4110: a nullability the inference already proves

**Warning.** Found applying the config file to what was inferred. The run goes ahead.

## What it means

`"nullable": false` where haruspex already proves the value is never null.

## Why haruspex reports it

The file shrinks as the SQL improves: an override the inference agrees with can go.

## What to do

Remove it.

## Example

```text
haruspex.json:1:122: warning HAR4110: procedures["lib.get_book"].paths["[].id"]: "nullable": false agrees with the inference, which already proves the value at results[0][].id is never null. Remove it.
```
