# HAR3112: a reference outside the schema

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A `$ref` outside the schema's own definitions.

## Why haruspex reports it

A declaration is one schema; a reference to another document can't be followed.

## What to do

Refer to `#/$defs/…` or `#/definitions/…` of the same schema.

## Example

```text
haruspex.json:1:135: error HAR3112: procedures["lib.p"].results.json.$ref: can refer only to "#/$defs/…" or "#/definitions/…" of the same schema.
```
