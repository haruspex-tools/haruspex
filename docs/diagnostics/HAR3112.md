# HAR3112: a reference outside the schema

**Error.** Found reading the config file, or a column's schema named in the SQL. It stops the run: nothing is written.

## What it means

A `$ref`, a column's `json`, or a column's `haruspex.jsonSchema` extended property, naming a schema on the network or anywhere
but a local file.

## Why haruspex reports it

A schema is never fetched: a build would then depend on someone else's server, and the schema could change under the same name.

## What to do

Keep a copy of the schema beside the one that refers to it, and refer to the copy by its path, relative to the referring file.

## Example

```text
haruspex.json:1:135: error HAR3112: procedures["lib.p"].results.json.$ref: refers to https://example.com/order.schema.json, which is not a local file: haruspex never fetches a schema, so keep a copy beside this one and refer to it.
```
