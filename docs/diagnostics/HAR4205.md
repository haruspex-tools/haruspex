# HAR4205: values unknown after a call that isn't followed

**Warning.** Found applying the config file to what was inferred. The run goes ahead.

## What it means

Values a procedure reads from a temporary table filled by `INSERT … EXEC` of a call haruspex doesn't follow are unknown.

## Why haruspex reports it

A declaration of the call's results can't help: what a call does to temporary tables is never known from it.

## What to do

Override the value's path under `paths`, with `type` and `import`.

## Example

```text
haruspex: warning HAR4205: lib.p: results[0][].id is unknown: #s may be changed by the call at p1.sql:3:1, which is not followed: EXEC (N'SELECT 1') runs dynamic SQL, a string built when the procedure runs, so its result sets are not known. A declaration can't type it: after a call that is not followed, temporary tables are unknown even when its results are declared. To type the value, override its path under "paths" with "type" and "import".
```
