# HAR3113: a reference to nothing

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A `$ref`, or the pointer after `#` in a column's `json`, whose JSON Pointer names nothing in its file.

## Why haruspex reports it

A reference to nothing has no type.

## What to do

Add the definition, or correct the pointer: `#/$defs/person` names the key `person` of the key `$defs`.

## Example

```text
haruspex.json:1:135: error HAR3113: procedures["lib.p"].results.json.$ref: refers to "#/$defs/missing", which names nothing: a fragment is a JSON Pointer, such as #/$defs/person.
```
