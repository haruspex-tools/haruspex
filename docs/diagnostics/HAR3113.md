# HAR3113: a reference to nothing

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A `$ref` to a definition the schema doesn't have.

## Why haruspex reports it

A reference to nothing has no type.

## What to do

Add the definition, or correct the reference.

## Example

```text
haruspex.json:1:135: error HAR3113: procedures["lib.p"].results.json.$ref: refers to "#/$defs/missing", which the schema does not define.
```
