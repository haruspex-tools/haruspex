# HAR6044: several sources name a project or a package

**Error.** Found on the command line. It stops the run: nothing is written.

## What it means

The command line gives several sources, and one of them is a `.sqlproj` or a `.dacpac`. Several sources are read as one
database, so each must be a folder of `.sql` files.

## Why haruspex reports it

A project or a package is a whole database of its own, with its own references and its own default collation. Read beside
other folders, which of those holds isn't clear, so haruspex reads a project or a package only alone
([decision 0127](../decisions/0127-a-source-may-be-several-folders.md)). The same rule in the config file's `source` is an
error of the config file ([HAR3005](HAR3005.md)).

## What to do

Give the `.sqlproj` or the `.dacpac` alone, or give only the folders of `.sql` files the database is in.

## Example

```text
haruspex: error HAR6044: release.dacpac is a .dacpac, a whole database, so it can't be read with other sources: give it alone, or give only folders of .sql files.
```
