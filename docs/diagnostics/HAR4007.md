# HAR4007: a queries entry names no query file

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

An entry of `queries` (a folder, a file or a pattern) names no `.sql` file of this module. A file below a folder that holds a
`haruspex.json` of its own is that module's, so an entry that names only such files names none of this one's, and the message
says so.

## Why haruspex reports it

A typo would otherwise drop the functions of the files it meant without anyone noticing.

## What to do

Correct the entry, or remove it. A pattern names files by their paths relative to the config file's folder, in the case they
are written in: `*` is any characters but `/`, `**` any folders, and `?` one character.

## Example

```text
haruspex.json:1:88: error HAR4007: queries: "sql/**/*.query" names no query file of this module. Correct it, or remove it.
```
