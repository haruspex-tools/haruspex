# HAR1014: a query file isn't one batch

**Error.** Found reading the SQL. It stops the run: nothing is written.

## What it means

A query file named by `queries` holds no statement, or `GO` splits it into several batches. A query file is sent to the server
as one batch, through `sp_executesql`, and `GO` is no part of SQL: it is a separator that SSMS and sqlcmd act on, which the
server would refuse.

## Why haruspex reports it

The file's function would run what the file doesn't say: one batch of several, or nothing at all.

## What to do

Make the file one batch: remove `GO`, and split work that needs several batches into several files, or into a procedure. A file
that is only a comment so far can be left out of `queries` until it holds the query.

## Example

```text
sql/q.sql:1:1: error HAR1014: sql/q.sql isn't one batch: GO splits it into 2 batches; GO is no part of SQL, but a client's separator, and a query file is run as one batch.
```
