# HAR3016: a rowset declared as maybe absent

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

`mayBeAbsent` on a rowset.

## Why haruspex reports it

A rowset with no rows is still a result set; only a JSON result can be missing (`FOR JSON` over no rows returns none).

## What to do

Remove `mayBeAbsent`, or declare the result as `json`.

## Example

```text
haruspex.json:1:115: error HAR3016: procedures["lib.p"].results: "mayBeAbsent" is for a JSON result, which FOR JSON leaves out when it matches no rows; a rowset with no rows is still there.
```
