# HAR2013: jSON whose shape isn't visible

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

JSON whose shape isn't visible here, such as JSON text read from a column. The value, or the result, is unknown in the
output, with this reason, and the generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Override the value's type in the config file, with a schema your application exports (`type` and `import`).

## Example

```text
db/p1.sql:1:34: note HAR2013: lib.p results[0][].data: json_query(b.extra) reads JSON that is not built here, so its shape is unknown.
```
