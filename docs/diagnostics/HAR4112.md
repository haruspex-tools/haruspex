# HAR4112: set names that don't match the result sets

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

A procedure's `sets`, or a query file's `-- @sets` comment, names more or fewer result sets than the procedure or file is known
to return, or names sets whose results can't be listed.

## Why haruspex reports it

A procedure's sets are named all or none, in order, so that its function returns one regular object, and a list left behind
when a set is added or removed can't give one set another's name
([decision 0070](../decisions/0070-a-procedure-s-result-sets-are-named-all-or-none.md)).

## What to do

Give one name for each set it returns, in order, or remove the names. For a procedure's results that can't be listed, declare
them under `results` first.

## Example

```text
haruspex.json:1:119: error HAR4112: procedures["lib.get_book"].sets: names 2 result sets, but lib.get_book returns one result set. Name every set it returns, in order, or none.
```
