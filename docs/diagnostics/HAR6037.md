# HAR6037: no IR to explain

**Error.** Found by `haruspex explain`. Nothing is printed but the error, with exit code 1, or 2 when nothing names an IR file.

## What it means

`explain` reads the committed IR, `haruspex.ir.json`, and it found none to read: the config file's output folder holds none,
no config file names an output folder and `--ir` names no file, or the file there is of another version or isn't IR.

## Why haruspex reports it

Every reason `explain` gives is in the IR, which an application's repository keeps beside the generated code; without it
there is nothing to explain from, and the SQL alone isn't read.

## What to do

Run `haruspex generate` to write the IR, or name the file with `--ir`. A file of an older version is written again by the
`generate` of this version.

## Example

```text
haruspex: error HAR6037: no IR to read: name it with --ir, or run where haruspex.json names the output folder that holds it.
```
