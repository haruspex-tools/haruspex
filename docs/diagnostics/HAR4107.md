# HAR4107: nullability declared for JSON text's content

**Error.** Found applying the config file to what was inferred. It stops the run: nothing is written.

## What it means

`"nullable": false` on what JSON text holds (`<json>`).

## Why haruspex reports it

The content of JSON text is never null itself; there is nothing to declare.

## What to do

Override the JSON text itself, or remove it.

## Example

```text
haruspex.json:1:122: error HAR4107: procedures["lib.get_book"].paths["[].one<json>"]: the value at results[0][].one<json> is what JSON text holds, which is never null itself; nothing can be declared about its nullability.
```
