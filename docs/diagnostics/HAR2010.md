# HAR2010: a result column without a name

**Note.** Found inferring the results. The run goes ahead; a note never changes whether it succeeds.

## What it means

A result column without a name, such as an expression with no alias. The value, or the result, is unknown in the output,
with this reason, and the generated schema accepts anything there.

## Why haruspex reports it

The output never claims more than SQL Server guarantees: what haruspex can't prove, it says it doesn't know, so the
output stays true. The note says where, so that an unknown is never silent.

## What to do

Give the column an alias (`AS name`).

## Example

```text
db/p1.sql:1:34: note HAR2010: lib.p results[0]: The column at p1.sql:1:34 has no name.
```
