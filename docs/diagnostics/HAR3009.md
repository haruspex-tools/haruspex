# HAR3009: an exclude without an include

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A schema's block has an `exclude` but no `include`.

## Why haruspex reports it

Without an include nothing in the schema is selected, so the exclude could never exclude anything; it can only be stale.

## What to do

Add the include the exclude was meant to narrow, or remove the exclude.

## Example

```text
haruspex.json:1:86: error HAR3009: schemas.audit.exclude: does nothing without an "include" in the same block, since nothing in the schema is selected. Add the include, or remove the exclude.
```
