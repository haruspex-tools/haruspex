# HAR3014: paths beside declared results

**Error.** Found reading the config file. It stops the run: nothing is written.

## What it means

A procedure has both declared `results` and `paths`.

## Why haruspex reports it

A declaration says everything about the results; a path override is for results haruspex infers.

## What to do

Put the detail in the declared schema, and remove `paths`.

## Example

```text
haruspex.json:1:109: error HAR3014: procedures["lib.get_book"]: "paths" can't be used with "results": the declared schema says it all, so put the detail there.
```
