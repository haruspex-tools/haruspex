# Support

**There is no support commitment.** This is a personal open-source project, offered under the
[Apache 2.0 licence](LICENSE) "as is": no one is obliged to answer a question, fix a bug, review a pull request or keep a
feature, and nothing has a promised response time. It is also pre-release, so the command line, the generated code and the
IR may change without notice.

Help is still welcome, in both directions:

- **A question or a bug:** open an issue on GitHub. A bug report is most useful with a small, invented database project that
  shows it, the command run and what it printed. Please don't post a real organisation's SQL.
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md) says, never in a public issue.
- **A fix or an improvement:** see [CONTRIBUTING.md](CONTRIBUTING.md).

If your team needs a tool with a support contract, haruspex isn't one today.
